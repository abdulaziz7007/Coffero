# Coffee House Premium Web App

Yangi mukammallashtirilgan va animatsiyali React Web Ilovasi!

### Yangi Funksionallik va Imkoniyatlar:
1. **Framer Motion Animatsiyalari**: Sahifalar o'rtasida ravon va chiroyli o'tishlar.
2. **Onlayn Buyurtma va Savat (Cart Context)**:
   - Mahsulotlarni hajmi (Kichik/O'rtacha/Katta) va shakar darajasi bo'yicha sozlab savatga qo'shish.
   - Savatda miqdorni oshirish/kamaytirish, umumiy summani hisoblash.
3. **Checkout (Buyurtmani rasmiylashtirish)**: Yetkazib berish manzili va to'lov turini tanlash.
4. **Auth Tizimi (Login & Register)**:
   - Kirish va Ro'yxatdan o'tish sahifalari.
5. **Profile Sahifasi**:
   - Foydalanuvchi ma'lumotlari.
   - Buyurtmalar tarixi (Order History).

### Ishga Tushirish Yo'riqnomasi:
1. ZIP faylni kompyuteringizga yuklab oling va papkaga chiqaring (Extract).
2. Terminalda loyiha papkasiga kiring:
   ```bash
   cd coffee-house-pro
   ```
3. Kerakli barcha kutubxona va bog'liqliklarni o'rnating:
   ```bash
   npm install
   ```
4. Loyihani dev-serverda ishga tushiring:
   ```bash
   npm run dev
   ```
